# Step 01 — Load the draft and gather the app's real facts

All commands run at the monorepo root `/Users/msindoni/Projects/appgrove`. The skill is invoked as
`/finalize-landing <app_id>`.

## Precondition gate — a draft must exist

```bash
APP_ID="<app_id>"
ls "site/src/content/landings/$APP_ID/"   # atteso: en.ts it.ts fr.ts es.ts de.ts index.ts
```

If the folder is missing, **stop**: the draft is generated by `/new-application` (UC 0046), not here. Tell the
developer:

```
🛑 Nessuna bozza di landing per "<app_id>". La bozza la crea /new-application (UC 0046).
   Esegui prima /new-application, poi torna a /finalize-landing <app_id>.
```

The tool enforces the same precondition (`finalize.mjs` stops if the folder is absent), but check it here so the
conversation starts from the right place.

## Read the draft

Read the five language files and `index.ts`. Note what is placeholder and must change:

- the hero `badge` carries the sentinel `«DA RIFINIRE»` in every language (the preflight rejects it until removed);
- `hero.screenshot.src` is `null` (placeholder box) — step-03 fills it with the real screenshot;
- `meta.ogImage` is `null` — step-03 fills it with the generated social image;
- the copy is **generic** on-brand text with the app name substituted — step-02 refines it on the real features.

## Gather the app's real facts

The refinement needs the truth about the app, which lives elsewhere in the repo. Collect:

- **App name** and **what it actually does** — the domain, now that the app exists (not the placeholder job).
- **Category colour and icon** — from the frontend module manifest
  (`frontend/apps/backoffice/src/modules/<app_id>/manifest.ts`): the accent token (`cat-*`) and Material Symbols
  icon. These feed the Open Graph image (`--accent`) and keep the landing on-brand.
- **Real features** (3–6) — from the app's UI/domain, to replace the generic feature copy.
- **Pricing** — from `services/core/src/main/resources/pricing/<app_id>.yaml`: tier names, prices, free cap,
  trial. The landing's pricing section must match the real listino (the numbers of record are in pricing-as-code).
- **Quota metric** — the `--metric` and free cap, for the screenshot seed and any usage copy.

Write down these facts (they drive step-02 and step-03). If the app is not really MVP yet — no real features,
no pricing decided — say so and stop: finalising a landing for an app that does not exist yet would put
unverifiable claims online (the same reason `new-application` leaves it a draft).

Proceed to `step-02-copy.md`.
